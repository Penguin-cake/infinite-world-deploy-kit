## 每份参赛作品的人工验收

以下由主办方对具体作品签核，平台提供试玩与验收入口。不能用平台单测替代作品验收。

- [ ] 作品名称与队伍已确认
- [ ] 缺少特定上家道具时有兜底玩法
- [ ] 开局前 5 秒没有即死陷阱
- [ ] 90–150 秒体感时长和提示清晰
- [ ] 连续阵亡后的 assist 档位确实改善难度
- [ ] 叙事承接平台钩子，无出戏台词
- [ ] 音乐、美术和 IP 授权已核实
- [ ] 大屏、键鼠或手柄可用
- [ ] 该作品外链及其资源允许嵌入并能加载
- [ ] 如使用 Unity/Godot，已用实际 Web 导出包完整试玩
- [ ] 验收人、日期和结论已记录

生产口令轮换属于运维操作。本轮在隔离环境验证轮换逻辑，未替换主办方现有口令。
